# DraftSteppe

DraftSteppe leverages cloud-agnostic infrastructure as code to streamline workflow for DraftSteppe projects: Core, Enterprise, Pro, Lite, Hub, Studio.

With DraftSteppe, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftSteppe.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DraftSteppe, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
